# Freedom Planner — Project Context

This file contains project-specific defaults. Update it as the project evolves.

## Product

A personal finance and financial-freedom planning application focused on India and INR.

Potential user goals include:
- financial health assessment
- debt planning
- savings/investment planning
- insurance/financial-cover assessment
- retirement/FIRE planning

## Financial safety

Financial calculations must be grounded in supplied inputs and explicit deterministic assumptions.

Do not:
- invent balances
- invent interest rates
- invent returns
- invent tax benefits
- guarantee savings or investment outcomes
- present estimates as facts

Use INR where the product requires it.

## AI advisor

The AI financial advisor should be cautious and transparent.

When information is missing:
- state the missing input
- avoid fabricating it
- provide a conditional explanation where useful

Project-specific financial rules should be maintained in the actual product specification, not inferred by the AI.
