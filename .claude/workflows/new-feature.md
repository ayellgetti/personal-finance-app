# /new-feature

Deliver a new feature through the repository's existing development process.

1. Understand the current behavior and relevant files.
2. Confirm requirements, scope, and acceptance criteria.
3. Plan the smallest architecture-compatible change.
4. Implement only after the scope is clear or the plan is approved.
5. Add or update meaningful tests.
6. Review security, performance, and backward compatibility.
7. Run repository-required validation and update affected documentation.

Do not skip required human approval for major architectural decisions.
